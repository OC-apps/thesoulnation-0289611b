# Instrucciones del proyecto The Soul Nation

## Motion design y video por código

Antes de crear o editar animaciones, lee `brand.md`, `MOTION.md` y `docs/motion-workflow.md`. Usa las skills instaladas en `.agents/skills/` según la tarea.

- Para referencias y dirección visual: `reference-to-motion` y `motion-brief-writer`.
- Para efectos y movimiento: `motion-effects` y `title-sequence-3d`.
- Para composiciones React y exportación: `remotion-create`, `remotion-markup` y `remotion-render`.

Nunca alteres, redibujes o deformes el logotipo oficial. No cambies las páginas, imágenes, textos ni configuración del sitio por el simple hecho de crear una animación. El material experimental va en una carpeta aislada y solo se integra en producción tras aprobación.

Para stingers OBS exige transparencia real, corte sin fugas (pantalla cubierta completamente en el punto de transición) y comprobación por fotogramas. Entregar HTML editable + archivo WebM alfa cuando se solicite exportación.

## Origen de skills

Las skills provienen de proyectos públicos de terceros y se usan como referencias de trabajo por agentes compatibles, no como actualización de los modelos ChatGPT. Consulta `docs/motion-workflow.md` para fuentes y límites.
